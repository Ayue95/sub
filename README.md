# Sub 本地化工具

短剧出海本地化流程用的网页工具。**纯前端**，所有处理都在浏览器里完成，字幕、视频、Excel 不会上传到任何服务器。

## 功能

| 功能 | 说明 |
|---|---|
| 一键立项 | 选择位置，填写剧ID + 剧名 → 一键生成标准的本地化多层级文件夹 |
| 原剧体检 | 选择原剧 → 查出缺集、空集、重复集与命名不规范集，显示全部集帧率 |
| ST ↔ TT | 选择本地化清单与译前字幕 → 一键替换术语并自检 |
| SRT 修复 | 选择译后字幕 → 修复时间轴、编码、行尾与语言混杂 |

## 怎么用

**方式一：本地打开（Windows）**

双击 `一键启动.bat`，浏览器会自动打开 `http://127.0.0.1:8017`。

需要电脑里装有 Python 3。脚本会自动查找，找不到会提示。

**方式二：线上访问**

见仓库的 Pages 地址。

## 浏览器要求

- 推荐 **Chrome / Edge 桌面版**（完整功能）
- 「选择文件夹」依赖浏览器的 File System Access API，**手机和 iPad 不支持**，只能用「选择文件」然后下载压缩包
- 首次打开需要下载 Python 运行环境（十几 MB），之后走缓存

## 技术说明

- 前端：原生 HTML / CSS / JavaScript，无构建步骤
- Python 运行时：[Pyodide](https://pyodide.org/)（Python 编译成 WebAssembly，跑在浏览器里）
- 字幕处理：[pysubs2](https://github.com/tkarabela/pysubs2)
- 视频参数解析：直接读取 MP4/MOV 的 box 结构，不依赖 ffmpeg
